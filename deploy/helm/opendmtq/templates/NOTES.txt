OpenDMTQ {{ .Chart.AppVersion }} is starting in namespace {{ .Release.Namespace }}.

Phones on the same network reach it at:  http://{{ .Values.publicHost }}/
That address must be where the "{{ include "opendmtq.fullname" . }}" Service answers on port {{ .Values.router.service.port }}.

  kubectl -n {{ .Release.Namespace }} logs -f job/{{ include "opendmtq.fullname" . }}-builder

Health:  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}

  kubectl -n {{ .Release.Namespace }} get secret {{ default (printf "%s-admin" (include "opendmtq.fullname" .)) .Values.admin.existingSecret }} -o jsonpath='{.data.ADMIN_PASSWORD}' | base64 -d

  kubectl -n {{ .Release.Namespace }} port-forward deploy/{{ include "opendmtq.fullname" . }}-api 8791:8000
